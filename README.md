One original line of fortune-cookie wisdom for a software developer, written by a program to `/output/entry.txt`:

> The reviewer who asks nothing has already found everything.

The line is 59 characters, inside the 120-character cap. It is a single balanced sentence in fortune-cookie voice: a quiet truth about code review — the reviewer who says nothing at all is the one who has already seen everything — with the twist landing on the last word.

## Run

```sh
node main.ts --output ./out
```

`MAKEFUN_OUTPUT_DIR` is honoured first, then `--output`, then `/output`.
